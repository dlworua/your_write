**Month 1-2: 자체 인증 서버 개발**
```

- DB: PostgreSQL (사용자 정보)

- POST /auth/register
- POST /auth/login
- POST /auth/refresh
- POST /auth/logout
- POST /auth/social/google
- POST /auth/social/apple
- POST /auth/social/kakao
- POST /auth/social/naver

보안:
- bcrypt 비밀번호 해싱
- Rate Limiting
- HTTPS 필수
```

**Month 3: 서버 인프라 구축**
```
클라우드 선택: Naver Cloud Platform (권장)
- 이유: 국내 속도, 한국어 지원, 저렴

구성:
- API 서버 2대 (로드 밸런싱)
- PostgreSQL (Primary + Replica)
- Redis Sentinel
- CDN (이미지 최적화)

예상 비용: 월 40-60만원
```

```
3. 소셜 로그인 재연동 요청
4. 병행 운영 (1개월)
5. 완전 이전
```

```
   - 정산 승인 (작가 후원, 출금 신청)

7. 팝업/공지 관리 ⭐ 상시 팝업
   - 팝업 생성/수정/삭제
   - 표시 기간 설정
   - 타겟 설정 (전체/특정 등급/특정 유저)
   - 이미지/텍스트 업로드
   - 미리보기
   - 활성화/비활성화

8. 통계
   - 회원 통계 (가입, 탈퇴, 활동률)
   - 게시글 통계 (작성, 삭제, 카테고리별)
   - 매출 통계 (일별, 월별, 연도별)
   - 인기 키워드
   - 트래픽 분석

9. 설정
   - 관리자 계정 관리
   - 권한 설정 (Super Admin, Admin, Moderator)
   - API 키 관리
   - 감사 로그 조회
```

**3중 보안 체계**
```
1단계: IP 화이트리스트
- 관리자 IP만 접속 허용
- 회사 네트워크 또는 VPN 필수

2단계: 2FA (Two-Factor Authentication)
- Google Authenticator 연동
- 로그인 시 OTP 6자리 입력 필수

3단계: 감사 로그 (Audit Log)
- 모든 관리자 작업 기록
- 누가 (관리자 ID)
- 언제 (타임스탬프)
- 무엇을 (액션: 수정, 삭제, 차단 등)
- 어떤 데이터 (대상 사용자/게시글 ID)
- IP 주소
- 로그 보관: 최소 1년, 삭제 불가
```

**네이버 스마트스토어 느낌**
```
- 직관적인 대시보드
- 실시간 데이터 업데이트
- 빠른 검색 및 필터링
- 일괄 작업 (선택 삭제, 일괄 처리)
- 엑셀 내보내기
- 알림 시스템 (긴급 신고, 결제 오류 등)
```
