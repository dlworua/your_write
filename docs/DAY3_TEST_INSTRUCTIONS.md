## 📱 테스트 방법

### 1. 앱 실행

```bash
# iOS 시뮬레이터에서 실행
flutter run

# 또는 Android 에뮬레이터에서 실행
flutter run
```

### 2. 테스트 페이지 접근

1. 앱 실행 후 로그인
2. 하단 네비게이션에서 "마이페이지" 탭 클릭
3. 우측 상단의 **버그 아이콘** (🐛) 클릭
4. "Cloud Function 테스트" 페이지로 이동

### 3. Cloud Function 호출 테스트

**테스트 페이지에서:**

1. **현재 사용자 확인**: 상단에 로그인된 이메일이 표시됨
2. **프롬프트 입력**: 기본값 "안녕하세요! 간단한 자기소개를 작성해주세요." 또는 원하는 텍스트 입력
   - 최소 10자 이상
   - 최대 5000자 이하
3. **"Cloud Function 호출" 버튼 클릭**
4. **로딩 표시**: 버튼이 로딩 상태로 변경됨
5. **결과 확인**:
   - ✅ **성공 시**: 녹색 박스에 AI 생성 텍스트 표시
   - ❌ **실패 시**: 빨간색 박스에 에러 메시지 표시

### Firebase Console에서 확인

1. [Firebase Console](https://console.firebase.google.com/) 접속
2. 프로젝트: **your-write**
3. **Functions** 탭 클릭
4. **대시보드** 탭에서 호출 횟수 확인
5. **로그** 탭에서 실시간 로그 확인:
   - `🔐 사용자: [UID]`
   - `✍️ 프롬프트 길이: [숫자]`
   - `✅ AI 생성 성공, 길이: [숫자]`

## 🐛 예상 에러 및 해결 방법

### 에러 1: "로그인이 필요합니다"
```
원인: Firebase Auth에 로그인되지 않음
해결: 앱에서 로그아웃 후 다시 로그인
```

### 에러 2: "프롬프트는 10-5000자 사이여야 합니다"
```
원인: 입력한 프롬프트가 너무 짧거나 김
해결: 10자 이상, 5000자 이하로 입력
```

### 에러 3: "internal: AI 생성 중 오류가 발생했습니다"
```
원인: Gemini API 호출 실패
해결:
1. Firebase Functions 로그 확인
2. Gemini API 키 확인: firebase functions:config:get
3. 할당량 초과 여부 확인
```

### 에러 4: "PERMISSION_DENIED"
```
원인: Cloud Functions 호출 권한 없음
해결:
1. Firebase Console > Functions > 권한 확인
2. Firestore Security Rules 확인
```
